## 🎮 Como rodar o controlador:
-  Certifique que você possua o Python 3.12 instalado.
-  Clone o repositorio com `git clone https://github.com/Inovatech-LTDA/Robo-Sapo.git`
-  Crie um VENV na raiz do projeto(Robo-Sapo), utilizando: `python3.12 -m venv env`
-  Ative o VENV na raiz do projeto com `source env/bin/activate` <- se você utilizar um sistema unix/unix-like, se for windows: `PS C:\>env\Scripts\Activate.ps1` ou `C:\>env\Scripts\activate.bat`
-  Instale os requirements.txt para conseguir utilizar as bibliotecas utilizadas no codigo. `pip install -r requirements.txt`
-  Rode o Controller `python3.12 Controller.py`
